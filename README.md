# Banking-Application-
Hey, I made a Banking Application with a GUI that simulates basic Internet Banking. You can securely log in, deposit and withdraw money, check your balance, and change your username or password. Hope you like my project and the effort behind it. Please leave a star if you enjoyed it. Thank you!

### How to Open the Banking Application

1. Switch the branch from **Main** to **Master**.
2. Open the **src** folder.
3. Access the Java source files and run the application from your IDE.

**Note:** The project source code is currently available in the **Master** branch.
