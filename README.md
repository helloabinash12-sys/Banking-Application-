# Banking Application (Java GUI)

This is a Banking Application developed using Java GUI. The project simulates basic internet banking operations and provides a simple, user-friendly interface for managing an account.

## Features

* Secure login system with username and password authentication
* Deposit money into your account
* Withdraw money from your account
* Check current account balance
* Change username and password
* Multiple user accounts supported

This project was created to practice Java programming, GUI development, and basic banking system concepts. It demonstrates user authentication, account management, and transaction handling in a desktop application.
